# Fix Forward — Campus Maintenance Demo

A responsive, dependency-free HTML, CSS, and JavaScript prototype for campus facility maintenance requests.

## Demo features
- Role-based demo entry for students, maintenance staff, administrators, and guests.
- Maintenance request form with categories, priorities, location details, image preview, and required-field validation.
- Student request tracking, request details, progress timeline, and local notifications.
- Staff request review, workflow updates, resolution notes, and assigned task view.
- Administrator assignment, user overview, sample-data reset, and request analytics with CSV export.
- Search, status/category/priority filters, sorting, pagination, notification preferences, dark mode, and responsive layouts.
- Sample request records and an in-app Privacy Policy.

## Run locally
Open `index.html` in a modern browser. All sample and newly entered data is stored in that browser's local storage.

## Important limitations
This is a single-browser demo, not a production maintenance or authentication system. Demo role selection is not secure authentication, role checks are not enforced by a server, and local records do not reach campus staff or sync between devices. Do not enter real passwords or sensitive information, and do not rely on this app for emergencies. A real deployment needs a secure backend, authentication, server-side access controls, reliable storage and backups, and a reviewed privacy policy.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `privacy.html`, `README.md`, and the complete `assets/` folder to the repository root.
3. Go to Settings → Pages; select deploy from a branch, choose `main` and `/ (root)`, then save.
4. Wait for the published URL to appear, then test the live site on desktop and mobile.
5. Confirm the Privacy Policy contact route and add a monitored project email address before public use, if available.
6. Use real screenshots and the actual published URL in your final report.
